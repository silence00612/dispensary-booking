# Запись пациентов на приём: клиентская часть

Курсовой проект по МДК 05.01. Сайт больницы с онлайн-записью к врачу.

**Демо:** https://silence00612.github.io/dispensary-booking/

## Возможности
- запись к врачу в четыре шага: врач → дата и время → данные → подтверждение;
- перенос и отмена записи в разделе «Мои записи»;
- раздел «Наши врачи» с фильтром по отделениям;
- окно «Срочная помощь» (103, 112, адрес приёмного отделения);
- адаптивная вёрстка для телефона.

## Технологии
HTML5, CSS3, JavaScript (без фреймворков). Данные хранятся в `localStorage`.

## Запуск
Скачайте репозиторий и откройте `index.html` в браузере. Сервер не нужен.

## Структура
- `index.html`: страница
- `css/`: стили
- `js/booking.js`: данные, слой `api`, мастер записи
- `js/script.js`: меню и маска телефона

## Ограничения
Записи хранятся только в браузере пациента. Серверной части нет.
